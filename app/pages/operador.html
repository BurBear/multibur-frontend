Pausar trabajo
Pausa operativa Usa este formulario cuando vas a cambiar de trabajo o dejar este proceso pendiente para retomarlo despues.

Pausa

  1. Registra el motivo de la pausa y, si hace falta, una observacion.
  2. La sesion actual se cerrara y el trabajo quedara disponible para retomar.
  3. Luego podras continuarlo tu u otro operador.
Gestion de Incidencia
Registrar incidencia Usa este formulario solo cuando hubo un problema real en el proceso. La pausa operativa se maneja aparte.

Incidencia

  1. Registra el motivo y la observacion del problema real.
  2. Guardar la incidencia no pausa automaticamente el trabajo.
  3. Si el trabajo ya no puede continuar, usa DEVOLVER A PLACAS.
